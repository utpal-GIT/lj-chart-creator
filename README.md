# LJ Chart Creator with Westgard Rules

Clinical QC Levey-Jennings Chart application built with Streamlit.

## Quick Start

```bash
pip install -r requirements.txt
streamlit run lj_chart_app.py
```

## Features

- **LJ Chart** — Interactive Levey-Jennings chart with Plotly
- **LJ Configurer** — Parameter & QC Lot-wise Mean/SD setup
- **Westgard Rules** — 1-2s, 1-3s, 2-2s, R-4s, 4-1s, 10x
- **Failure Analysis** — Detailed troubleshooting for each violation
- **Import/Export** — CSV data and JSON configurations
- **Sample Data** — One-click demo data with built-in violations
